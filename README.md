# MultiLingual Assistive Device (MAD) - Stage 3

## Overview
This was a group project done in University of Western Ontario

In this stage, the **Raspberry Pi 3 B+** was set up with all the necessary dependencies. The hardware wiring of the LCD screen was completed, and the **translation function** was fully implemented for all languages supported by the **Google API**. Additionally, a **history log** is recorded for tracking translations.

At this stage, there is **no graphical user interface (GUI)**. Instead, the history log is saved in a separate text file generated by the program.

## Project Goal
The primary goal of this device is to **eliminate the need for a laptop or external screen**, making it accessible solely through the LCD screen. However, for debugging purposes and for **TAs to evaluate our progress**, a console-based interaction has been implemented. This terminal-based version mimics the LCD output.

Thus, both the **LCD version** and the **console-based version** are included in the project.

## Requirements
To run this prototype, you need a **Raspberry Pi 3 B+** with the latest **Raspbian OS** installed.
Additionally, you need to install **three key libraries** that may not be pre-installed:

### 1. WiringPi (for GPIO control)
```sh
sudo apt-get install wiringpi
```
Alternatively, if WiringPi is not available:
```sh
git clone https://github.com/WiringPi/WiringPi.git
cd WiringPi
./build
```

### 2. cURL (for network requests)
```sh
sudo apt-get install libcurl4-openssl-dev
```

### 3. JSONCPP (for JSON parsing)
```sh
sudo apt-get install libjsoncpp-dev
```

## Running Without an LCD
If you are **not using the LCD**, you can **comment out all LCD-related lines** in the code. In this case, you do not need to install **GPIO libraries** or **WiringPi**. We handled this by using `delay()` to simulate interactions for the LCD.

## Future Plans
For future submissions, we plan to **statically link all libraries** so that no additional dependency installations will be required. However, due to time constraints, this was not implemented in the prototype. Since the final product is meant to be a **physical device**, software dependencies were not our main focus.

### Pre-Built Executable
If you are running this on a Raspberry Pi, we have included a **pre-compiled executable** (`program.exe`). This might work without needing to install dependencies. However, this is **just a test** and is **not officially part of the prototype**.

## Compilation & Execution
After installing all dependencies, compile the program using:
```sh
g++ -o Hardware Hardware.cpp -lcurl -ljsoncpp -lwiringPi -lwiringPiDev
```
Then, run the program:
```sh
./Hardware
```

The program is **user-friendly** and provides instructions inside.

## Usage Instructions
1. **Choose Language 1** (source language)
2. **Choose Language 2** (target language)
3. **Translate** text between the two languages

## Accessing the Translation History
All translations are logged in **`HistoryLog.txt`**. You can manually edit or manipulate this file if needed.
